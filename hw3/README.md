# HW3 – Full Stack Frameworks and Libraries

## Introduction

For this homework, I worked with different frameworks, libraries, and APIs to learn more about full-stack web development.

I completed two tutorials and one exercise using the Rick and Morty API.

## 1. React Tutorial – Tic-Tac-Toe

I completed the React Tic-Tac-Toe tutorial. I learned how to use React components, manage state, and handle user clicks to create a working game.

**How to run:**
1. Open the `react-tutorial` folder in the terminal.
2. Run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000` in a browser.

## 2. Socket.IO Tutorial – Chat Application

I completed the Socket.IO basic chat tutorial. I learned how to connect users and send messages between browsers in real time.

**How to run:**
1. Open the `socketio` folder in the terminal.
2. Run `npm install`.
3. Run `node index.js`.
4. Open `http://localhost:3000` in two browser windows to test the chat.

## 3. Rick and Morty API Exercise

For this exercise, I created an Express application using the Rick and Morty API and Pug templates.

The application includes these routes:

- **Home (`/`)** – Displays a welcome page.
- **Characters (`/characters`)** – Displays the first 100 characters with their names, pictures, species, and status.
- **Species (`/species`)** – Groups characters by species and displays the number of characters and their names.
- **Locations (`/locations`)** – Groups locations by type and displays the number of locations and their names.

**How to run:**
1. Open the `countries-app` folder in the terminal.
2. Run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000` in your browser.
5. Visit the different routes to view the results.
